# 🎬 Pagina Multimedia Modernă

## 📖 Descriere

Acest proiect reprezintă o pagină web multimedia modernă creată folosind **HTML5** și **CSS3**. Scopul paginii este de a demonstra integrarea diferitelor tipuri de conținut multimedia precum imagini, fișiere audio, video locale și videoclipuri YouTube, împreună cu un design modern și responsive.

---

## 🎯 Obiectivele Proiectului

- Utilizarea elementelor multimedia HTML5
- Crearea unui design modern folosind CSS
- Integrarea conținutului video și audio
- Implementarea iframe pentru conținut extern
- Organizarea conținutului folosind layout tip card
- Aplicarea efectelor vizuale moderne (blur, shadow, gradient)
