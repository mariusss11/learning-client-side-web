# 🌍 Cele 7 Minuni ale Lumii Antice – Pagina Web Informativă

## 📖 Descriere

Acest proiect reprezintă o pagină web educațională care prezintă **Cele 7 Minuni ale Lumii Antice**. Scopul proiectului este de a demonstra utilizarea elementelor HTML pentru structurarea conținutului, integrarea imaginilor, link-urilor externe și a hărților interactive.

Pagina oferă informații istorice, descrieri, imagini și resurse suplimentare pentru fiecare minune a lumii antice.

---

## 🎯 Obiectivele Proiectului

- Demonstrarea structurii unei pagini HTML complete
- Utilizarea elementelor de formatare a textului
- Crearea listelor HTML
- Integrarea imaginilor externe
- Inserarea unei hărți Google Maps folosind iframe
- Utilizarea hyperlink-urilor externe
- Aplicarea stilizării prin fișier CSS extern

---

## 🧩 Funcționalități

### 📄 Conținut Informativ
Pagina conține:
- Introducere despre cele 7 minuni ale lumii
- Lista completă a monumentelor
- Definiții și explicații istorice
- Secțiuni dedicate fiecărei minuni
- Concluzie și surse informative

---

### 🖼️ Elemente Multimedia

Proiectul include:
- Imagini reprezentative pentru fiecare minune
- Hartă interactivă Google Maps pentru Marea Piramidă din Giza
- Link-uri externe către surse documentare

---

### ✍️ Elemente HTML Utilizate

#### Formatarea Textului
- `<strong>` – eviderează text important  
- `<em>` – evidențiază text accentuat  
- `<mark>` – evidențiază text cu fundal colorat  
- `<small>` – afișează text mai mic  
- `<del>` – indică text șters  
- `<ins>` – indică text adăugat  

---

#### Liste
- Listă neordonată pentru prezentarea minunilor
- Listă de definiții pentru explicații suplimentare

---

#### Alte Elemente
- `<img>` – afișarea imaginilor
- `<iframe>` – integrarea hărții Google Maps
- `<a>` – link-uri externe
- `<hr>` – separatoare între secțiuni
