# HTML Formatting and Lists Demonstration

## 📖 Overview
This project is a simple HTML document created to demonstrate fundamental HTML elements such as text formatting, lists, and document structure. It is intended for educational purposes and beginners learning HTML.

---

## 🧩 Features

### 🔤 Text Formatting Elements
The document demonstrates the usage of the following HTML tags:

| Tag | Description |
|------|------------|
| `<b>` | Displays bold text |
| `<strong>` | Displays important text (semantically strong) |
| `<i>` | Displays italic text |
| `<em>` | Displays emphasized text |
| `<ins>` | Displays inserted text |
| `<mark>` | Highlights text |
| `<u>` | Underlines text |
| `<s>` | Displays strikethrough text |
| `<del>` | Displays deleted text |
| `<small>` | Displays smaller text |
| `<sup>` | Displays superscript text |
| `<sub>` | Displays subscript text |

---

### 📄 Text Containers
The project includes examples of:

- Paragraph formatting using `<p>`
- Preformatted text using `<pre>`
- Horizontal separators using `<hr>`
